# Como precificar primeiro projeto de freelancer

O primeiro projeto não precisa ser barato só porque você está começando. O que importa é fechar um valor justo que cubra seu tempo e mostre profissionalismo.

## Erro comum

Muitos precificam por “o que o cliente quiser pagar”. Isso queima preço logo na primeira entrega e fica difícil subir depois.

## Critério mínimo

1. Calcule horas previstas
2. Multiplique por um valor/hora mínimo aceitável
3. Some custos diretos, se houver
4. Ajuste conforme a complexidade

## Exemplo simples

- 10 horas previstas
- R$ 30/hora como base inicial
- Sem custos extras
- Valor sugerido: R$ 300

## Quando aceitar menos

Se o projeto for curto e você quiser um case, pode aceitar um pouco menos. Mas não faça disso regra.

## Como apresentar o valor

- Mostre o escopo fechado
- Mostre o prazo
- Mostre o que está incluso
- Não peça desculpas pelo preço

Cliente que entende o que recebe não briga por R$ 20 a menos.
