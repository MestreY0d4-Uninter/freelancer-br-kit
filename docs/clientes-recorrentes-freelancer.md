# Clientes recorrentes para freelancer

Freelancer que depende só de projeto novo todo mês vive de oscilação. O que costuma mudar isso não é mais proposta, é transformar cliente único em cliente recorrente.

## O que costuma gerar recorrência

- Follow-up curto e consistente
- Relatório simples de resultado
- Pequena manutenção mensal
- Check-in sem desculpa “só para acompanhar”
- Entrega no prazo como padrão

## Pacotes que funcionam

- Manutenção mensal
- Acompanhamento semanal
- Suporte administrativo recorrente
- Produção de conteúdo por lote

## Como propor sem parecer invasivo

1. Após entrega, envie resumo do resultado
2. Sugira um acompanhamento leve, com valor fechado
3. Dê exemplo de próximo passo
4. Deixe o cliente decidir o ritmo

## Por que isso ajuda

Quando o cliente sabe o que recebe todo mês, ele deixa de comparar preço por hora e começa a comparar resultado por valor.

Cliente recorrente não precisa ser grande. Precisa ser previsível.
