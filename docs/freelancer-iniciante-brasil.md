# Freelancer iniciante no Brasil

Começar como freelancer no Brasil não exige investimento alto, exige rotina: oferta simples, proposta direta e acompanhamento curto.

## O que fazer primeiro

1. Escolha um serviço que você já sabe fazer
2. Prepare 2 exemplos curtos
3. Monte uma proposta padrão enxuta
4. Defina um valor/hora mínimo
5. Escolha uma plataforma e envie propostas diárias

## Plataformas possíveis

- 99Freelas para serviços curtos
- Upwork/Fiverr para demanda internacional
- GitHub Pages + Gumroad para produto digital
- LinkedIn para serviços B2B

## Erros que atrasam

- Proposta genérica sem personalização
- Textão na primeira mensagem
- Sem exemplo ou prova
- Sem follow-up após envio

## Quando escalar

Depois de 3 entregas bem avaliadas, aumente preço, restrinja nicho e documente cases.

## Ferramenta mínima

Base estruturada de clientes, projetos e pagamentos reduz retrabalho e ajuda a medir evolução mês a mês.
