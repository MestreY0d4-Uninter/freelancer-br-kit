# Freelancer BR Kit

Se você é freelancer no Brasil e ainda usa anotações soltas, planilha sem estrutura e lembrete no WhatsApp para saber se o cliente pagou, este kit foi feito para reduzir esse caos rápido.

O **Freelancer BR Kit** é um conjunto mínimo de planilhas para você parar de perder dados e começar a medir o que realmente importa: **faturamento, cliente por cliente, projeto por projeto e impostos por mês**.

## O que você ganha agora (gratuito)

1. **Clientes** — base com nome, email, WhatsApp, PJ/PF e condições de pagamento
2. **Projetos** — descrição, valor, prazo, status e data de entrega
3. **Pagamentos** — tudo que entrou, com data e cliente
4. **Impostos** — estimativa simplificada para MEI / Simples Nacional
5. **Leia-me** — instruções de uso em 5 minutos

Arquivos CSV prontos para importar no Google Sheets: **Arquivo → Importar → Upload**.

## Quando vale a pena ir para a versão completa

Se você já atende mais de um cliente por mês e quer parar de calcular na mão, a versão completa do Freelancer BR Kit entrega:

- dashboard automático de faturamento
- acompanhamento de valores pendentes e recebidos
- controle de impostos integrado
- template de proposta comercial pronto
- fórmulas prontas para DAS/INSS

Tudo dentro de uma planilha Google Sheets editável, sem instalação.

## Como começar em 3 passos

1. Baixe os arquivos deste repositório
2. Importe no Google Sheets
3. Preencha a base de clientes e projetos

Se depois de uma semana os CSV gratuitos resolverem sua rotina, ótimo. Se faltar estrutura, a versão completa existe exatamente para isso.
