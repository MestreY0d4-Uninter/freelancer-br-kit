# Preço de freelancer: como saber se está barato ou caro

Muitos freelancers abaixam preço por medo de perder cliente. O que costuma ajudar não é tabela pronta, é critério claro: valor entregue, tempo real e estrutura de custos.

## Critério mínimo

- Quanto tempo o projeto vai levar no total?
- Qual o custo da sua estrutura para esse trabalho?
- Qual o resultado que o cliente ganha?
- Quanto você cobraria para ter folga e continuar evoluindo?

## Quando o preço baixo realmente vale

- Para construir histórico e reviews
- Quando o projeto for case que você quer mostrar
- Quando o prazo for curto e você tiver disponibilidade

## Quando o preço baixo prejudica

- Quando vira regra para todos os clientes
- Quando o projeto for grande e complexo
- Quando você já tem entregas anteriores para mostrar

## Como testar sem risco

1. Aumente 10% nas próximas 3 propostas
2. Meça taxa de resposta
3. Se não mudar, aumente mais
4. Se cair, ajuste sem voltar ao valor antigo

## O que muda a percepção

- Escopo fechado por escrito
- Prazo com data, não “em breve”
- Exemplo de entrega anterior
- Proposta curta, sem textão

Cliente não paga pelo seu tempo, paga pelo resultado que entende.
