# Como funciona o 99Freelas para iniciantes

99Freelas é uma das plataformas mais usadas por freelancers no Brasil. Para iniciantes, o que costuma fazer diferença não é criar conta, é usar a plataforma com rotina: proposta curta, follow-up leve e entrega no prazo.

## Cadastro

- Crie conta com email válido
- Preencha perfil com habilidades reais
- Adicione exemplos, mesmo que simples
- Não deixe o perfil em branco

## Proposta

- Personalize a primeira linha
- Deixe escopo fechado
- Coloque prazo e valor claros
- Evite textão na primeira mensagem

## Primeiro projeto

- Aceite valor menor nas primeiras entregas
- Entregue no prazo
- Peça feedback
- Documente o resultado

## Quando aumentar preço

Depois de 3 entregas bem avaliadas, suba gradualmente. Repetir valor baixo para sempre limita crescimento.

## Dica prática

Se você quer começar sem complicação, pode usar um conjunto simples de planilhas para clientes, projetos e impostos. Importa em minutos e começa a organizar.
