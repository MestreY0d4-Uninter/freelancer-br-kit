# Como funciona o Freelancer BR Kit

O Freelancer BR Kit é um conjunto de planilhas CSV para Google Sheets / Excel criado para quem trabalha como freelancer e precisa organizar clientes, projetos, pagamentos e impostos sem complicação.

## O que é

São arquivos CSV prontos para importar:
- `1_README.csv` — instruções rápidas
- `2_CLIENTES.csv` — base de clientes
- `3_PROJETOS.csv` — controle de projetos
- `4_PRE-PROJETOS.csv` — levantamento inicial de escopo
- `5_PAGAMENTOS.csv` — registro financeiro
- `6_IMPOSTOS.csv` — estimativa simplificada de impostos

## Quando usar a versão gratuita

- Você atende poucos clientes por mês
- Quer começar sem complicação
- Precisa só de estrutura mínima

## Quando usar a versão completa

- Você já tem mais de um cliente ativo
- Quer dashboard automático
- Quer template de proposta comercial incluso
- Quer controle de impostos integrado

A versão completa está no Gumroad: [Freelancer BR Kit completo](https://yodabug.gumroad.com/l/tsohs)
