# Como organizar finanças de freelancer no Brasil

Ser freelancer no Brasil exige mais do que entregar o trabalho: é preciso controlar quem pagou, quem falta, quando vence o imposto e quanto realmente entra no mês.

A maioria dos profissionais usa mistura de WhatsApp, caderno e planilha solta. O problema não é falta de dado, é falta de estrutura mínima.

## Um fluxo simples que funciona

1. **Cadastre cada cliente em uma linha** — nome, email, WhatsApp, tipo PJ/PF e condições de pagamento
2. **Abra um projeto por entrega** — valor, prazo, status e data real de entrega
3. **Registre cada pagamento** — data, cliente, valor e forma de pagamento
4. **Atualize o saldo semanalmente** — valores pendentes, recebidos e a receber
5. **Calcule impostos todo mês** — DAS, IRPJ ou simples nacional, conforme seu regime

## O que costuma quebrar a rotina

- Anotar pagamento só no WhatsApp e depois perder o histórico
- Misturar valores de projetos diferentes na mesma conta
- Deixar para calcular impostos só na hora de declarar
- Não ter data de entrega definida por escrito

## Ferramenta mínima

Para quem quer começar sem complicação, um conjunto de planilhas CSV para Google Sheets já cobre o essencial:

- base de clientes
- controle de projetos
- registro de pagamentos
- cálculo simplificado de impostos

Importa em menos de 5 minutos e usa sem instalação.

## Quando trocar de planilha solta para sistema

Se você já atende mais de um cliente por mês e sente que está recalculando a mão toda semana, vale investir em uma versão com fórmulas prontas e dashboard automático.
