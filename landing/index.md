# Você ainda anota cliente no WhatsApp?

Se você é freelancer no Brasil e ainda usa mensagem solta, planilha sem estrutura e lembrete mental para saber se o cliente pagou, este kit foi feito para tirar esse caos em 5 minutos.

## O problema

- Você não sabe quanto falta receber no mês
- Cliente some depois da proposta
- Imposto surpreende na hora de declarar
- Trabalho barato vira rotina porque não tem métrica

## A solução

O **Freelancer BR Kit** é um conjunto mínimo de planilhas Google Sheets para você medir o que realmente importa:

- ✅ Base de clientes (nome, contato, PJ/PF, condições)
- ✅ Controle de projetos (escopo, prazo, status)
- ✅ Registro de pagamentos (o que entrou e o que falta)
- ✅ Estimativa de impostos (MEI / Simples)
- ✅ Instruções de uso em 5 minutos

## Gratuito ou Completo?

**Gratuito:** os 5 arquivos CSV prontos para importar.

**Completo (Gumroad):** dashboard automático, acompanhamento de pendentes, controle de impostos integrado, template de proposta comercial e fórmulas prontas de DAS/INSS.

👉 **[Quero a versão completa agora](https://yodabug.gumroad.com/l/tsohs)**

## Comece hoje

1. Baixe os arquivos deste repositório
2. Importe no Google Sheets (Arquivo → Importar → Upload)
3. Preencha a base de clientes

Se depois de uma semana os CSV resolverem sua rotina, ótimo. Se faltar estrutura, a versão completa existe exatamente para isso.
