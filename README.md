# Freelancer BR Kit 🇧🇷

Kit de planilhas CSV prontas para abrir no Google Sheets / Excel e organizar sua vida como freelancer no Brasil.

## O que vem
| Arquivo | Para que serve |
|---|---|
| `1_README.csv` | Instruções de uso |
| `2_CLIENTES.csv` | Cadastro de clientes e contatos |
| `3_PROJETOS.csv` | Controle de projetos, prazos e status |
| `4_PAGAMENTOS.csv` | Registro de pagamentos recebidos |
| `5_IMPOSTOS.csv` | Cálculo simplificado de imposto mensal (MEI/simples) |

## Como usar
1. Baixe os 5 arquivos CSV
2. No Google Sheets: **Arquivo → Importar → Upload**
3. Pronto — comece a preencher
